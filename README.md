One prompt, one game: my AI agent built **HANSZY COIN RUSH** — a tiny browser game where an orange cat collects gold coins against a 30-second timer — from a single prompt, while I watched. The video of it being built is posted on X; this repository hands in that post's address. Play the game in `game/` (open `index.html`, move with arrow keys or WASD, or add `?auto=1` to watch it play itself).

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
